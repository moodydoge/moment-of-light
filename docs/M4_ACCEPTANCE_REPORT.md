| 年龄策略 | 仅有成人声明勾选，**不等于**核验 |
| 托管鉴权与审计 | 当前访客 HMAC + 本地 SQLite，缺生产级账号与审计 |

## 8. 下一步真实用户测试方案（建议）

1. 邀请 3–5 名校内测试者，发放**邀请口令**（仍不开放公开池）。  
2. 两人一组走完：AI → 发起 → 申请 → 确认 → 聊天 → 结束 → 反馈。  
3. 第三人尝试越权（应失败）。  
4. 收集：退出是否好找、举报是否敢用、文案是否清楚「非心理咨询」。  
5. 记录危机提示是否打扰正常倾诉（误触率）。
