# Milestone 3 双浏览器验收步骤

前置：`npm run dev`，打开两个浏览器配置文件（或普通窗口 + 隐私窗口）。

## A. 真实连接

1. **浏览器 A**：进入「先聊一会儿」→ 开始 AI 陪伴 → 完成成年访客声明 →「邀请真人」→ 确认开放。  
2. **浏览器 B**：进入「看看善意」→ 完成访客声明 → 看到 A 的真实请求 →「愿意陪伴」→ 确认。  
3. **浏览器 A**：聊天页出现申请 → 接受。  
4. 双方互发文字，确认可见对方真人标签。  
5. 任一方结束 → 双方进入反馈。

## B. 并发匹配

用三个身份：A 发请求，B/C 几乎同时申请；A 接受 B 后，再接受 C 应失败。

## C. 权限隔离

第三人拿着 sessionId 调 API 读消息，应返回无权。

## D. AI 回归

真人加入前 AI 可聊；加入后 AI 不自动抢答，仅可选话题建议。
