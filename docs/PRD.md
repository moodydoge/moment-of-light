# 产品需求文档（PRD）— 此刻有光

## 定位

**此刻有光**是一个面向广泛社区场景的轻量善意触发器。

一句话描述：当你想找人说说话时，AI 可以先陪你聊聊；如果你愿意，也可以邀请一位真实的人，分享几分钟善意。

核心理念：**AI 托底，真人传递善意。**

不以恋爱交友、长期社交或专业心理咨询为目的。

## 两类用户

### 发起者

希望获得一点陪伴的人。可先与 AI 交流，再自主决定是否开放短暂真人陪伴请求。

### 响应者

愿意贡献 5—10 分钟的人。可查看匿名请求、自主选择是否参与，双方确认后进入文字交流。

## 业务流程

1. **流程 A：发起陪伴** — 首页 → 先聊一会儿 → AI 聊天 →（可选）邀请真人 → 等待/确认 → 结束反馈  
2. **流程 B：响应善意** — 看看善意 → 选择请求 → 确认接入 → 交流 → 结束反馈  
3. **流程 C：无人响应** — AI 可持续；如实显示等待；可取消请求；不虚构预计时间

## MVP 边界（Milestone 1）

包含：可交互前端原型、演示服务适配层、安全相关 UI/类型/接口边界。

不包含：真实大模型、真实实时通信、正式云资源开通。

## 公益机制

一次主动响应 = 一次轻量善意行动。

不将聊天时长、消息数或点击反馈直接等同于经核实的公益成效；反馈仅为用户主观表达。
