# 安全与信任边界 — 此刻有光

## 已落实（Milestone 1–2）

1. 用户可随时结束会话；结束会 abort 进行中的生成。  
2. 真人接入需确认面板 + 双方确认状态（等待 → 申请 → 确认）。  
3. 默认不公开完整 AI 对话历史；不将私聊默认同步到响应池。  
4. 提供「举报」「阻止」入口（演示写入 FeedbackService）。  
5. 公共请求不展示联系方式、精确位置或自由文本私密内容。  
6. AI 消息强制标注「AI 陪伴」；演示回复标注「演示」；live 与 demo 分离。  
7. 不虚构在线人数、匹配成功假象；演示操作有明确标注。  
8. 文案声明：非专业心理咨询 / 非紧急援助。  
9. 危机关键词触发服务端附加提示，要求审慎支持并鼓励现实求助；不把普通响应者当危机处置人员。  
10. 未具备服务端保障前，不开放真实匿名陌生人聊天室。  
11. API Key 仅服务端环境变量；输入长度与调用频率有限制；上下文短窗口，默认不持久化私聊。

## 正式开放前必须具备

- 服务端授权与会话访问控制  
- 限流与基本防滥用  
- 内容治理、举报阻止处置闭环  
- 可靠年龄策略（不能仅靠前端勾选冒充验证）  
- 紧急求助引导的独立安全处理流程  

## 产品原则

- AI 永不假装真人  
- 真人永不被未验证地标成「社区志愿者」  
- 模拟模式不得包装成正式生产能力
